# AI Support Agent (Telegram)

An AI agent that handles customer and employee requests through Telegram, built with n8n and OpenAI.

## Features
- Automatically identifies whether the user is a customer or an employee and responds accordingly
- Escalates requests and complaints to management
- Hands urgent cases over to a human employee

## Tech Stack
n8n · OpenAI · Telegram
